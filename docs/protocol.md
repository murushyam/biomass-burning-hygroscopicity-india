# Analysis protocol

This file will record every design choice after the pilot phase, with a time stamp, before the main analysis begins. It is a placeholder at the proposal stage.

Items to be frozen here, following Sections 5 and 8 of [proposal.md](proposal.md):

- every Table 2 criterion tagged D (design choice), after pilot tests
- the fire-exposure threshold used to class a layer as smoke
- the RH error standard deviation used in the Monte Carlo ensemble
- the H2 critical-diameter margin, if the pilot replaces the 10 % starting value
- the H1 equivalence margin, if the pilot sample is too small for ±0.10
- the exact sub-region bounding boxes

No protocol values have been frozen yet. Do not treat the starting values in `configs/` as final.
